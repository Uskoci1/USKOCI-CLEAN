# 04 — MAP

**Product problem:** Select an opportunity without losing its location or covering the next action.

**Surface:** Map / list / selected preview. **Priority:** P1. **Design state:** RESEARCH; no approved composition.

## Synthesis constraints

One selection state must connect pin, preview and list. Keep selected context visible; remove competing action overlap. Never invent precise coordinates or turn remote work into a geographic point.
