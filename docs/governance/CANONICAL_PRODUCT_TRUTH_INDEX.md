# USKOČI canonical product-truth index

This is the minimum binding index for reconciling implementation work. A screen, SQL
function, or prototype is not a finished feature without the full evidence chain:

`DECISION → SCREEN/ACTION → FLOW/RETURN → SOURCE → BACKEND → TEST → PROOF`

## Locked principles

- One account may use both Requester and Worker workspaces. A local workspace switch is
  not an authentication or backend-authority switch.
- Requester navigation: Početna, Potrebe, central `+`, Dogovori, Profil.
- Worker navigation: Početna, Prijave, central USKOČI/Prilike entry, Dogovori, Profil.
- Server remains authoritative for Need, Response, selection, Agreement, completion,
  urgency, and other lifecycle mutations.
- AI proposes; a human reviews/confirms; the server validates and owns the canonical
  mutation. AI publishing remains `PACKAGE_4_NOT_READY` until the Package 4 safety and
  review boundary is implemented and proven.
- `Dogovor` is the central execution workspace, not merely a status card.
- Brand phrase: **MENI TREBA. JA MOGU.**
- Visual direction: premium, human, youthful, urban Serbia; cream/ivory operational
  base, controlled orange for action, forest/deep teal for trust. Avoid sterile luxury
  and an endless cream-card wall.
- Ports & Adapters remains the canonical client architecture. Donor repositories and
  HTML designs are evidence/logic/visual references, not production truth.

## Evidence classifications

- `SOURCE_EXISTS`
- `TEST_PROVEN`
- `DB_PROVEN`
- `AUTHENTICATED_RUNTIME_PROVEN`
- `RUNTIME_PROVEN`
- `DEVICE_PROVEN`
- `LOAD_PROVEN`

Never promote a feature past its strongest physical proof. Current concurrent UI work
is `SOURCE_EXISTS` and partially statically tested; it is not yet a production or
Package 4 completion claim.
