## Panels and cross-cutting states

Search/filter/calendar and selected/shared-point sheets are part of Discovery; public profile and offer comparison are contextual surfaces; task fact/place/photo/deadline editors belong to review; worker manual/availability/frozen review belong to setup; attachments/changes/problem/completion/contact belong to the Agreement; safety confirmations, closure review, support evidence and operator decisions remain distinct. Each must retain its current return path and command identity.

For each changed surface: initial load, refresh with content retained, genuine empty, filtered empty, partial/error/offline read, denied permission, pending/unknown/success write, changed account and vanished object where applicable. Do not manufacture irrelevant states. Plain success copy requires a confirmed result.
