The owner explicitly permits visible own tasks when distinctly marked: their presence is not the defect; unreliable recovery and ambiguous ownership are. Existing tests cover timeout and retained public data, but not same-ID retry recovery or distinct confirmed-own/confirmed-other/unknown presentation ([tests](../../../../src/data/__tests__/marketplace-owned-screens.test.tsx:62)).

**Smallest client-only package.** Retry both resources through the existing focus/account guard. Preserve task visibility, filter draft and viewport; replace default own-task exclusion with a distinct confirmed-own label. Distinguish confirmed-other from unknown ownership, and expose pending/unavailable status plus retry without treating failure as `NONE` or an empty result. Keep counts truthful to the visible filtered rows, rather than implying an ownership check succeeded. Existing application/detail guards remain authoritative: ownership uncertainty must not create application eligibility. The overlay already distinguishes `UNKNOWN` from `NONE`, so this needs no new RPC. Preserve account/ID coverage and generation retirement; prove visible own-task marking, unchanged visibility across ownership recovery, same-ID retry, changed IDs, timeout/late completion, blur/background and account ABA ([relation contract](../../../../src/data/taskRelation.ts:16), [resource retirement](../../../../src/data/focusedResource.ts:32)).
