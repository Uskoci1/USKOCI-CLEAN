# R17 — conversation and accepted work

Owner resumed the approved second composition batch on 25 September 2026. This is a client-only batch;
verification and device evidence are recorded separately. No source check is whole-journey or visual acceptance.

## Purpose and composition

| Surface | User's job | Change and reason |
| --- | --- | --- |
| Home | See what needs me and choose how to start | Keep the two illustrated starts and actual attention reasons; the upcoming appointment leads with the work, then time and person, without repeated decorative rails. |
| Agreements | Recognize accepted work and its next action | Work beside the existing portrait, supporting person/role, full-width accepted terms, separate real next action and rating target. Remove the cumulative side inset and tab-edge fading. |
| AI task and worker conversations | Turn my words into a draft I can review | Compact local draft disclosure, separate guarded review, quieter assistant groups and one composer edge. All frozen facts and recovery remain available. |
| Human and AI history | Read and reply without losing my place | Follow-latest intent belongs to user gestures or explicit actions; keyboard geometry does not cancel it. History context-height changes preserve the reading offset. |
| Filters and map | Refine jobs and return to the same place | People controls stack on the owner's narrow phone. Calendar endpoints use measured radii. Native fallback markers fit inside rich pins and remain available on failure. Restore the remembered visible map bounds once. |

The alternatives and source diagnosis are in
[the existing composition analysis](../design-diagnosis-20260925/REPORT.md).
This implements its second batch rather than reopening the whole design direction. Skills used: design-taste,
mobile-app-ui-design and animate-expo; the owner's white surfaces, ordinary strong text and native behavior override
generic web recipes. No new design library is required.

## Functional boundaries

- Home has no invented photo, price, location or attention fallback. Partial reads and legacy detail remain honest.
- Draft expansion is local UI state; worker review still owns `prepare()`. Safety notes, missing-map guidance,
  stable conversation identity, category masking and frozen review are preserved.
- Outbox identity, photo checks, uncertain-send retry, blocked actions and terminal history remain unchanged.
- No server, Edge, DEV, payment, dependencies, provider calls, microphone or real business command changed.
- The map fallback is not hidden based on speculative bitmap readiness; the installed SDK has no such callback.
- Restoring visible bounds is a mount behavior, not automatic camera steering after every sheet movement.
