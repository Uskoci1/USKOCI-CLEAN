# PKG-011 — Accessibility plan and status (V19 PKG-011 test: 200% text, screen reader, reduced motion; disabled/loading/empty/error states)

Date: 2026-09-16. Applies to every surface rebuilt in slices 1–7. Device acceptance (real phone, TalkBack/VoiceOver, 200% font, reduced motion on) belongs to PKG-017/PKG-021 and is not claimed here.

## What the rebuilt presentation guarantees by construction

| Requirement | How it is met | Where it is proven locally |
|---|---|---|
| Text scales to 200% without clipping the primary action | No fixed-height rows; footers and cards use `minHeight`, wrapping rows (`flexWrap`) for price/people and action groups; `T` never goes below 12px (`theme/tokens` type scale); brand actions are full-width in footers. | Slice tests assert content by text and label, independent of layout; `raspored` already switches its time rail off above `fontScale 1.3`. |
| Screen reader: roles, names, states, order | Every interactive element is a `Press`/`V2Action` with `accessibilityRole` and a stable `accessibilityLabel` (the parity contract of the existing suites); segmented controls are `tablist`/`tab` with `selected`; radios/checkboxes carry `checked`; disclosure rows carry `expanded`; headers use `accessibilityRole="header"`; skeletons are `importantForAccessibility="no-hide-descendants"` with a polite live status; sheets set `accessibilityViewIsModal`. | `pkg011-slice1…6-presentation`, `pkg011-intent-transition`, `pkg011-agreement-workspace` assert roles/states/labels. |
| Reduced motion | Sheets use `animationType="none"` when the OS preference is on (`src/ui/system/motion.ts` for system components, reanimated `useReducedMotion` where the harness already isolates it); `Press` skips scale on reduced motion; no decorative entrance/shimmer motion on lists or skeletons. | `pkg011-intent-transition` (none vs slide), `marketplace-presentation` (filter sheet). |
| Disabled / loading / empty / error / unknown states | Each rebuilt screen renders: skeleton + spoken status when loading; a concrete error message with one retry; an empty state with one useful action; disabled actions with `accessibilityState.disabled`; unknown outcomes keep their command identity and name the readback action (existing engine copies). | Slice tests cover loading/empty/error per surface; existing recovery suites cover unknown outcomes. |
| Color never alone | Status always pairs a dot/chip with text; selected segments change shape and weight; brand action is orange surface with ink text (AA 5.1). | Token file documents every checked pair. |

## Permission denials (owner decision 4)

Microphone, camera/photos, location and notifications are requested only in context. A denial shows the existing plain-language copy plus `PermissionRecovery`: **Podešavanja telefona** (opens the OS settings) and the named alternative — type instead of speaking, pick from the gallery, continue the Agreement without sharing a location, or keep in-app notifications. Nothing re-requests silently or claims a grant.

## Open for device acceptance (PKG-017 / PKG-021)

- 200% text on the real Android renderer for the densest cards (TaskCard with three tags, AgreementCard with problem chip, comparison columns).
- TalkBack reading order on the map preview sheet and on the intent transition sheet.
- Reduced motion with MapLibre camera moves (`DiscoveryMap` already jumps instead of easing).
- Haptics and press feedback on the physical device (`Press` runs on the UI thread).
