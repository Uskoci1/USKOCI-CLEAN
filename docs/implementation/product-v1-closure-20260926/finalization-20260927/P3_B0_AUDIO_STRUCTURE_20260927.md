# P3 / B0 — bounded audio structure admission

2026-09-27. **SOURCE-ONLY VALIDATOR HARDENING / LOCAL CHECKS PASS. VOICE MESSAGES ARE NOT SHIPPED.**

The old M4A helper accepted an `mp4a` byte string anywhere inside `moov` and a declared movie duration. It did not establish an audio track, decoder configuration or a relationship between the sample tables and the media bytes. A video handler, second track, malformed sample table and fake marker could pass that gate.

Only `supabase/functions/_shared/voiceM4a.mjs` and `supabase/proofs/chat/voice_m4a.test.mjs` change. Admission now walks the actual hierarchy and requires one self-contained mono AAC-LC track: `soun` handler, version-0 `mp4a` description, bounded MPEG-4 ES/DecoderConfig/AudioSpecificConfig descriptors, local data reference, supported 8–48 kHz rate, identity transforms, and consistent movie/track/media/sample durations. Sample counts, sizes, timing, description indices and chunk offsets must account for the entire single `mdat` without gaps, overlaps, out-of-bounds references or unreferenced bytes. Parsing is bounded independently of attacker-supplied counts.

The existing 4 MiB / 300 ms / 300,000 ms limits and return envelope are unchanged. Versions 0/1 of time headers, `stco`/`co64`, fixed/per-sample sizes, extended `mdat`, media-before-metadata order and 1–4-byte descriptor lengths are covered. Unknown layouts fail explicitly: edits, fragmentation, metadata trees/tracks, video, multiple tracks, protection/encryption, external references, HE-AAC/SBR/PS and codec extensions. This is a deliberately narrow admitted subset, not broad MP4 support.

**Limit:** fixtures contain consistent AAC-LC declarations/tables with synthetic opaque sample bytes. They are not native recordings or decoder-validated sound. A deliberate test confirms opaque zeroed samples are still admitted: this helper does not decode, sanitize, transcode, prove playability or inspect spoken content. Real Android/iOS recorder fixtures and explicit compatibility decisions are required before using it as an upload gate; legitimate unsupported layouts must not be silently enabled. No microphone, provider, Storage or DEV call occurred; no package, UI, Edge deployment or certificate changed. Current runtime imports remain test-only. Full Jest/TypeScript/native runs do not establish anything additional for this isolated source-only helper and were not run.
