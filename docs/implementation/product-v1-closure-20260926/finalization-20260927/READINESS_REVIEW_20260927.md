## External quality baseline

- [Android core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality): use as an acceptance checklist for consistent behavior, accessibility, state restoration, responsiveness, stability and device verification. These are not all identical store rejection rules.
- [Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/): completeness/reviewer access and operational UGC safeguards matter alongside visual polish.
- [Google Play account deletion requirements](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en): assess both the in-app request path and functional web resource, with accurate disclosures.
- [Google Play UGC policy](https://support.google.com/googleplay/android-developer/answer/9876937?hl=en): terms, reporting/blocking and ongoing moderation require a functioning product/process, not only buttons.

There is no single universal premium-app certification. Release quality must be demonstrated across product behavior, accessibility, reliability, privacy, operations and the platforms actually being shipped.
