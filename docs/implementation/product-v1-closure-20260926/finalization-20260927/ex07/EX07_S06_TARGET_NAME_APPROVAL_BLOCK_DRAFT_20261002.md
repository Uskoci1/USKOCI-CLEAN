## The defect (gap G11 of `EX07_CANONICAL_SCOPE_20261001.md`)
The safety screen (`/bezbednost`) is opened with an account id and says only "Korisnik je blokiran / nije blokiran": a person who is about to block or report somebody is not told WHO. The plan (card N06) requires that the displayed name belongs to the real target id, and a route parameter must not be trusted for it. `rpc_read_safety_target` (PKG-047a, ledger 199) returned ids and the caller's block revision only.
