## First CI run (36949455489, source f8e36e52): no defect of the candidate
42 checks passed on a real database (the pin gate 47 of 47, the atomic application with the certificate re-bound, old-client parity, the gates, visibility, RLS, moderation, both real closures, the export, the revert and the reapply, the weakening probes); 2 failed and 1 dependent was skipped. Both failures were defects of the PROOF, not of the candidate: (1) the anonymous legacy-versus-v2 comparison required byte-identical messages although the platform's refusal quotes the called function (fixed: the called name is masked and each message must name its own function); (2) the text of `'a' + U+DFFFF + 'b'` (a Unicode noncharacter, the code point just below the forbidden plane-14 block) was read back as `ab` through the proof's raw character transport while the function accepted it and returns its input untouched (fixed: every text travels as ASCII, base64 in and hex out, and the raw hops are measured separately; the candidate files and the manifest are byte-identical to before). The noncharacters are now explicit matrix cases; the forbidden class is deliberately not widened. See `README_D12_PROOF.md`, "After the first CI run".
